# Работа с исходниками

1. Прочитайте README.md и PRIVACY.md. Сохраняйте привычное оформление сайта и не добавляйте аналитику или удалённый исполняемый код.
2. Вносите изменения в `content/`, `background/`, `popup/` и `shared/`. Веб-сайт и его API могут меняться независимо от расширения.
3. Выполните `node tests/package.cjs` и `python tools/build.py`. Проверьте расширение в браузере на собственных тестовых данных.
4. Для изменений интерфейса проверьте мобильную ширину, ПК, отключение расширения, навигацию и штатные обработчики сайта.
5. Перед отправкой изменений уберите персональные данные, реквизиты доступа и снимки реальных переписок. Для ошибок используйте демонстрационные данные.

Полный браузерный сценарий описан в `tests/README.md`. Сохранённые файлы сайта не публикуются вместе с проектом.
