# Политика конфиденциальности GhostPLUS

Версия 1.0.0. Обновлено: 19 октября 2026 года.

GhostPLUS изменяет оформление GhostSocial V2 и показывает дополнительные сведения в профилях. Это независимое расширение.

## Локальная обработка

В постоянном хранилище браузера сохраняются только настройки: включение расширения, ширина ленты, цвет акцента, анимации, прозрачность, горячие клавиши, отображение дат, оценка дат, живые уведомления, звук и Windows-уведомления. В хранилище сессии Chrome сохраняются до 300 идентификаторов показанных системных уведомлений, идентификатор исходной вкладки и адресуемый пост/ник для перехода; они удаляются при завершении сессии браузера.

Во время работы на странице расширение локально обрабатывает имя пользователя и дату регистрации, если сайт предоставляет её. Для приблизительной оценки используются имена авторов и даты публикаций и комментариев, без копирования их текста. При необходимости через штатный API сайта запрашивается до трёх дополнительных страниц публикаций просмотренного аккаунта. До 200 профилей и сведений об активности хранятся только в памяти вкладки. После её закрытия или перезагрузки кэш исчезает. Описание профиля через канал данных расширения не передаётся.

Для панели непрочитанного локально обрабатываются до 150 уведомлений: идентификаторы уведомления и связанного поста, тип события, имя и ник автора, дата, состояние прочтения и короткий предпросмотр до 240 символов. Тексты хранятся только в памяти вкладки, без записи в постоянное хранилище браузера. При включённых Windows-уведомлениях имя автора и предпросмотр передаются локальному API уведомлений Chrome и могут отображаться и сохраняться центром уведомлений операционной системы. Личные переписки GhostChat не запрашиваются. Нажатие одного события устанавливает локальную отметку прочтения в текущей вкладке. «Прочитать все» по явному нажатию отправляет на сервер GhostSocial стандартную общую отметку; ошибка сервера не сбрасывает локальный счётчик.

Для размещения элементов расширение также читает разметку текущей страницы. Вставляемые сведения отображаются как текст.

На странице чата работают только CSS существующих галочек и переключение общего оформления. Сетевые запросы и тексты чата не читаются. Для добровольного статуса расширение отключает флаг обязательного окна в ответе страницы, не сохраняя текст статуса и не продлевая его на сервере.

## Передача данных

GhostPLUS не отправляет данные разработчику или третьим лицам, не использует аналитику и рекламу, не продаёт данные и не создаёт удалённый реестр пользователей. У расширения нет собственного сервера. Оно не читает пароли, токены авторизации, cookies, личные переписки или историю браузера. Дополнительные запросы к публикациям и уведомлениям направляются только существующему API GhostSocial через функции самого сайта. Авторизация выполняется сайтом; расширение не извлекает и не сохраняет реквизиты доступа.

Сведения пользователей используются исключительно для описанных функций интерфейса. Использование данных соответствует ограничениям Limited Use политики Chrome Web Store User Data Policy.

## Управление и удаление

Настройки можно сбросить в окне расширения. Звук и Windows-уведомления отключаются отдельно. Удаление расширения удаляет его локальные настройки. Закрытие вкладки удаляет кэш профилей и локальные отметки прочтения. Отображённые Windows-уведомления можно удалить средствами системы. Выключение оформления возвращает интерфейс сайта; для полного прекращения работы скриптов отключите расширение в браузере и обновите вкладку.
